# 面孔——抗战中的普通人

《中国近现代史纲要》第六章平时作业：抗日战争互动展示（参考三：AI 历史场景复原与考证）。

- **课堂展示 10–18 分钟（16 分钟展演版） + 300 字总结**。
- **选题**：不聚焦宏大战役，把镜头对准个体——在原 7 张档案照片基础上**择优删补**扩展为 **14 张抗战普通人面孔**（保留核心 7 张并从 `additional/` 精选增补 7 张，涵盖敌后生产教育民主与国际反法西斯战线，淘汰低清报刊翻拍与现代拼接图），形成 24 页交互展示。

## 诚实标注（展示时主动说明）

- **AI 涂错的帽徽与尺度对比**：远征军照片帽徽被 AI 涂成红色，实际国军帽徽是青天白日徽（蓝底白日）；军服也被涂得过分整齐。而在第 14 张《史迪威公路挂旗照》中，两面大尺寸盟国旗帜被 AI 准确上色，恰可作对照案例。
- **坚持不上色的三张**：上海南站婴儿、重庆大隧道惨案保持黑白原貌，白求恩手术照仅作黑白去噪增晰——给废墟幼童、遇难者遗体与血迹手术台强行上色有失真实与尊重；重庆大隧道照片在展示中默认模糊，点一下才看原图。
- **战地护士没有上色**：AI 上色一步未能通过，改用黑白原片只做缓慢推近。
- **择优删补与主题补齐**：大后方军需工厂女工原网传图无法核验授权，初版由滇缅公路筑路妇孺代位，二期增补精选了来源确凿的《晋察冀军区被服厂做军衣》（HKUST `x001338`）补齐战时被服生产维度；同时从 `additional/` 候选图中淘汰了 400px 低清报刊图、现代拼接边框图及重复题材照片，最终定稿为 14 张主面孔。
- **南侨机工车队照**：画面为滇缅公路运输车队，未注明驾驶者身份，是南侨机工工作场景配图，不可写成“图为南侨机工本人”；陈嘉庚合影约 1946 年于新加坡，战后不久，非战时合影。
- **数字口径**：军民伤亡 3500 万以上为 2015 年公布口径（1947 年国民政府统计为 1278 万余人）；重庆大隧道死亡人数说法从 900 余到 4000 余不等，展示写“约四千人，据美国国家档案馆原说明，学界估计不一”。
