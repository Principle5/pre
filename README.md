# 面孔——抗战中的普通人

《中国近现代史纲要》平时作业：抗日战争互动展示（参考三：AI 历史场景复原与考证）。

- **课堂展示 10 分钟 + 300 字总结**。
- **选题**：不聚焦宏大战役，把镜头对准个体——7 张抗战时期不同身份的人物老照片，AI 上色 + 微动效让静态面孔“活”过来，每张照片对应一个群体的抗战故事；国军、八路军与群众各界共同呈现，体现抗日民族统一战线。

## 诚实标注（展示时主动说明）

- **AI 涂错的帽徽**：远征军照片帽徽被 AI 涂成红色，实际国军帽徽是青天白日徽（蓝底白日）；军服也被涂得过分整齐、过分土黄，史料里的远征军军服是土布自染、混杂褪色的。
- **没有上色的两张**：上海南站婴儿、重庆大隧道惨案保持黑白原貌——给废墟中的婴儿与遇难者上色有“美化苦难”之嫌；重庆大隧道照片在展示中默认模糊，点一下才看原图。
- **战地护士没有上色**：AI 上色一步未能通过，改用黑白原片只做缓慢推近。
- **没找到的照片**：大后方军需工厂女工没有找到能核验授权的公开照片，滇缅公路女工替她站在“女性战时劳动”这个位置，缺口在展示里如实写明。
- **南侨机工车队照**：画面为滇缅公路运输车队，未注明驾驶者身份，是南侨机工工作场景配图，不可写成“图为南侨机工本人”；陈嘉庚合影约 1946 年于新加坡，战后不久，非战时合影。
- **数字口径**：军民伤亡 3500 万以上为 2015 年公布口径（1947 年国民政府统计为 1278 万余人）；重庆大隧道死亡人数说法从 900 余到 4000 余不等，展示写“约四千人，据美国国家档案馆原说明，学界估计不一”。
