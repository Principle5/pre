## 2. 南侨机工 —— 滇缅公路上的运输车队

- **主题**：南侨机工（南洋华侨机工回国服务团）
- **标题**：China-bound supply convoy travels up the Burma Road（运往中国的补给车队行进在滇缅公路上）
- **时间/地点**：1942–1945 年，滇缅公路（中缅边境—昆明段）
- **摄影者/来源**：美国陆军军事历史中心（U.S. Army Center of Military History），China Defensive 战区档案；Wikimedia Commons, File:China-bound convoy travels Burma Road.jpg
- **文件页 URL**：https://commons.wikimedia.org/wiki/File:China-bound_convoy_travels_Burma_Road.jpg
- **图片直链 URL**：https://upload.wikimedia.org/wikipedia/commons/7/7a/China-bound_convoy_travels_Burma_Road.jpg（实测 HTTP 200，103KB，642×468）
- **版权**：Public domain（美国陆军官方照片）
- **统一战线一句话**：1939–1942 年，3200 余名南洋华侨青年应陈嘉庚号召回国，在滇缅公路上抢运 50 余万吨抗战物资、1000 余人牺牲——照片上的美制卡车车队正是他们驾驶、守护的“抗战生命线”。
- **核查说明（必须在 PPT  captions 中如实交代）**：画面本身是滇缅公路运输车队，未注明驾驶者身份，**不能写成“图为南侨机工本人”**；它是南侨机工工作场景的配图。Commons 上未找到有战时南侨机工个人影像的文件（仅见纪念碑、纪念馆等现代照片），这是该方向的素材缺口。文件页浏览器打开被 403，改由 Commons API 元数据核验；原图已下载目视确认（山路卡车队）。

## 3. 华侨支援 —— 陈嘉庚与李光前、陈六使（1946 年合影）

- **时间/地点**：约 1946 年，新加坡（战后不久）
- **摄影者/来源**：陈嘉庚纪念馆（Tan Kah Kee Memorial Museum）；Wikimedia Commons, File:Tan Kah Kee, Lee Kong Chian, and Tan Lark Sye, 1946.png
- **文件页 URL**：https://commons.wikimedia.org/wiki/File:Tan_Kah_Kee,_Lee_Kong_Chian,_and_Tan_Lark_Sye,_1946.png
- **图片直链 URL**：https://upload.wikimedia.org/wikipedia/commons/a/a6/Tan_Kah_Kee%2C_Lee_Kong_Chian%2C_and_Tan_Lark_Sye%2C_1946.png（实测 HTTP 200，395KB，933×674）
- **版权**：Public domain（Commons 标注）
- **统一战线一句话**：陈嘉庚任南洋华侨筹赈祖国难民总会主席，组织海外华侨捐款、汇款与义卖，并亲自招募 3200 余名南侨机工回国——华侨的钱、物、人都投入了抗战，课本第六章亦写明以陈嘉庚为主席的华侨筹赈总会“分支机构遍及南洋”。
- **核查说明**：照片摄于约 1946 年（战后不久），不是战时照片，PPT 中须注明年份，不可写成抗战期间合影。文件页浏览器打开被 403，改由 Commons API 元数据核验；原图已下载目视确认（三人西装合影）。
