## 4. 视频流水线：怎么重新渲染（本地 agent 照做）

工作目录：`~/workspace/video-united-front/`（下文简称 `BASE`）。全程 Python 3 + ffmpeg。

### 4.0 一句话流程

```
照片/影像分段渲染 → 字幕 SRT→ASS → 合成（xfade + 旁白 + 音乐 + 字幕）→ CRF 27 压到 ~40MB → 上传
```

### 4.1 分段渲染（照片）

```bash
cd ~/workspace/video-united-front
python3 render_clips_v2.py            # 全部重渲染（约 35 分钟）
python3 render_clips_v2.py A1 B1      # 只渲染指定分段
```

- 脚本：`render_clips_v2.py`，`JOBS` 列表定义每个分段（名字、源图、时长、推镜方向、题注、是否历史照片、章节标题）。
- 渲染：PIL 浮点裁剪 + LANCZOS + smoothstep 推镜（1.00↔1.09，平移 ±0.06）；颗粒（6 张循环噪声图）、暗角 1.0→0.82；题注 Noto Serif CJK 36pt 左上；章节标题金色（走向联合 / 两个战场 / 各界同心 / 后方 / 今天）。
- **字体关键**：只装了 Noto Sans/Serif CJK（.ttc）。`.ttc` 里字体顺序是 0=JP、1=KR、**2=SC**、3=TC、4=HK。
  PIL 默认用 index 0（日文），“关”字会又宽又扁。**所有题注/标题必须用 `ImageFont.truetype(path, size, index=2)`**（SC）。
  竖版照片用“模糊背景填充 + 整图适配”，不要硬裁成 16:9（台儿庄教训：只剩 46% 高度，只见躯干）。
- 渲染后若改过 A2/A3/B3/C2/D4（影像段），要重跑 `make_footage_clips.py` 覆盖掉照片版（见 4.2）。

### 4.2 影像分段（真实历史影像 / 视频）

```bash
python3 make_footage_clips.py   # A2、A3、C2、D4（B3 已在 v12 退役，见 README）
```

- 来源：《The Battle of China》（1944，Frank Capra，Why We Fight #6，美国战争部，**公有领域**），本地 `footage/battle_of_china_512kb.mp4`。
- 各段源时间（秒，±2 分钟，剪前核实）：A2 街头人群 1370、A3 行军涉水 3060、C2 滇缅公路盘山 2810、D4 大后方桥上人群 1970。B3 前线爆炸 3420（v12 已退役，不用）。
- **不要把通用影像题注成具体战役**（如不要把一段普通战斗标成“平型关”）。B3 之前题注特意写通用的“前线 · 1937年”，就是这个原因。
- E2 广州航拍、E3 广州夜景是单独剪的（Pexels，见 §3.2），不在 `make_footage_clips.py` 里；E2 推镜慢是正常的，它本来就是视频。

### 4.3 旁白

- 文案：`narration.md`（美化稿，1076 字），分段在 `narration/sec_A.txt`…`sec_E.txt`。
- 配音：用户选定 **#4 深沉男声**，TTS CLI：
  `/opt/hatch/bin/tts speak --voice avocado_v2:vd2_r8_rep1k_0104_v068_28k_g5k --language zh --speed 90 --output <mp3> --text-stdin`
  中文年份写成“一九三七年”。“四行仓库”读 sì háng：TTS 文本用“四航仓库”代替（字幕仍写“四行仓库”）。
- 各段时长（v6 后）：A 48.5s、B 50.2s、C 72.3s、D 47.4s、E 42.0s，总计 260.4s。

### 4.4 字幕

```bash
python3 build_subtitles.py   # narration → subtitles.srt（断句）
python3 build_ass.py         # subtitles.srt → subtitles.ass（72pt，底部钉死）
```

- **字幕 72pt**（v11 起，用户要求翻倍）。1280 宽每行约 17 个全角字。
- 断句规则（`build_subtitles.py` 的 `wrap_sentence`）：**只在 ，、；。：处断开**，绝不在词中切开。
  38 字以上的 6 条（#11、#14、#16、#20、#21、#42）及 #10、#26、#28、#36 共 10 条是三行，其余两行。
  “今天，我们生活在和平里。”断成“今天，/我们生活在和平里。”（“生活”完整）。
- `build_ass.py`：字体 `Noto Serif CJK SC`，每句带 `{\pos(640,690)}` 把字幕块钉在底部；
  三行 72pt 约 220px 高，顶边约 470，留在画面里。**不要改 \pos**。
- 字幕共 42 条。改完务必抽帧核实至少一条（重点 #35 在 239 秒处）。

### 4.5 合成

```bash
python3 assemble_v2.py
```

- 脚本：`assemble_v2.py`。`ORDER` 是 20 个分段顺序，`DURS` 是每段时长，`XF=0.8` 秒交叉淡化。
- 分段时间（v12）：title_open 10；A1 17.9、A2 17.9、A3 17.7；B1 19.3、**B2 12.0、B3 26.6**；
  C 15.5×4 + C5 15.3；D 13.1×4；E1 15.7、E2 15.7、E3 15.6；title_close 16。总计 **298.9 秒**。
- 合成：xfade 链 + 旁白（adelay/amix）+ `ass=` 字幕滤镜 + 音乐。
- **音乐动态**（v9 起）：开场 0.25 → 11.2 秒降到 0.15 → 旁白段 0.15 → 280.3 秒（最后旁白结束）后 2 秒内升到 0.40 → 保持到结尾 → 3 秒淡出。
- 合成输出约 250–325MB，再压：
  `ffmpeg -i united_front_video_v12.mp4 -c:v libx264 -pix_fmt yuv420p -crf 27 -preset medium -c:a copy -movflags +faststart <small>.mp4`
  约 39–44MB。**压完务必 ffprobe 验一下再替换**（之前有两次重编码被机器重启打断，留下坏文件）。
- 上传：`/opt/hatch/bin/remote-storage upload-file --path <file>`，链接 48 小时有效；>102MB 会 413 报错，40MB 左右没问题。

## 5. 内容事实（核查过的，别改错）
