# 本地用微软语音给视频配音（备用方案）

如果 Muse 这边实在连不上微软的语音服务，你可以在自己电脑上生成旁白，
再把音频发给我，我来合成进视频。

## 为什么用微软 Edge TTS
- 免费，不用注册、不用 API Key。
- 云阳（zh-CN-YunyangNeural）是深沉男声，很适合这个历史主题，比现在
  的 4 号声音更自然、更通顺。
- 也可以试试其他男声：云枫（zh-CN-YunfengNeural）、云健（zh-CN-YunjianNeural）。

## 步骤（Windows）

### 1. 装 Python
- 去 https://www.python.org/downloads/ 下最新版，安装时勾选
  “Add Python to PATH”。

### 2. 装 edge-tts
打开命令提示符（cmd）或 PowerShell，运行：
```
pip install edge-tts
```

### 3. 生成 5 段旁白
旁白文本在仓库 `video/narration/` 里（sec_A.txt ~ sec_E.txt）。
把这 5 个 txt 文件下载到电脑上，放到同一个文件夹，然后在该文件夹
打开 cmd，逐条运行（注意把 `+0%` 换成你想要的语速；`+0%` 是正常语速，
想慢一点用 `-10%`，快一点用 `+10%`）：

```
edge-tts --voice zh-CN-YunyangNeural --rate +0% --file sec_A.txt --write-media sec_A.mp3
edge-tts --voice zh-CN-YunyangNeural --rate +0% --file sec_B.txt --write-media sec_B.mp3
edge-tts --voice zh-CN-YunyangNeural --rate +0% --file sec_C.txt --write-media sec_C.mp3
edge-tts --voice zh-CN-YunyangNeural --rate +0% --file sec_D.txt --write-media sec_D.mp3
edge-tts --voice zh-CN-YunyangNeural --rate +0% --file sec_E.txt --write-media sec_E.mp3
```

注意：
- “四行仓库”在 sec_B.txt 里，Edge TTS 一般会读成 sì háng（正确）。
  生成后先听一下这一句，如果读成 xíng，告诉我，我再处理。
- 年份都写成“一九三七年”这种汉字形式，Edge 读出来才是对的，
  仓库里的文本已经是这种写法，不用改。

### 4. 把音频发给我
把生成的 5 个 mp3（sec_A.mp3 ~ sec_E.mp3）发给我（微信/下载链接都行），
我把它们替换进视频，重新合成一版。字幕和画面不用动，只换声音。

## 如果只想先试听一个声音
```
edge-tts --voice zh-CN-YunyangNeural --text "一九三七年，卢沟桥的枪声划破夜空，中华民族到了最危险的时候。" --write-media test.mp3
```
听一下 test.mp3，觉得合适再批量生成 5 段。
